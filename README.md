# Granger Causality Test: A Beginner's Guide

## Introduction

Granger causality is a statistical method used to examine whether past values of one variable help predict another variable. It is widely used in economics, finance, statistics, and time-series analysis.

## Data Requirements

To perform a Granger causality test, you generally need two time-series variables, regularly spaced observations, sufficient data, and an appropriate lag length. Data preparation and model assumptions should also be considered.

## Interpreting Results

The test produces a p-value. A p-value below 0.05 commonly indicates evidence that one variable provides additional predictive information about the other under the specified model. However, Granger causality does not prove actual cause and effect.
